使用说明：
    1，在电脑或者手机直接点击“singbox配置生成.html”文件。
    2，在打开的页面中，第一个节点链接方框中，粘贴你的 ssr、ss、v2ray、trojan、clash 的节点链接。
    3，在第二步中上传本工具附带的配置模板（或者你自己修改的配置模板），点击“生成配置”按钮。
    4，生成的配置文件会在当前目录下生成一个“singbox_config.json”文件。
    5，打开“singbox_config.json”文件，复制里面的内容。
    6，打开“singbox_config.json”文件，粘贴到你的 singbox 的配置文件中。
    7，保存配置文件，重启 singbox 即可。
    8，使用过程中如果有问题，请自行修改配置文件，或者在本工具的 GitHub 页面提问。
    9，感谢使用本工具，如果觉得好用，请给个 star，谢谢。

    注意：生成后的配置 json 中，有些节点参数不一定匹配到指定 tag，例如“美国”这个 tag，可能会匹配到其他节点 tag等，所以在使用过程中，如果发现节点不匹配，请自行修改配置文件中的 tag。
